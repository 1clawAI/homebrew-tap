# 1Claw Homebrew Tap

Homebrew formulae for [1Claw](https://1claw.xyz) — secrets management for AI agents.

## Install

```bash
brew install 1clawAI/tap/1claw
```

Or tap first, then install:

```bash
brew tap 1clawAI/tap
brew install 1claw
```

## Quick start

```bash
1claw setup    # Auto-configure Claude, Cursor, VS Code, etc.
```

## Update

```bash
brew upgrade 1claw
```
